# 产品定义方案（PRD V1.0）

> 出品：产品主理人（Phase 1）｜参考：`product-design.md`

## 一、目标与指标

| 类型 | 指标 | 目标值 | 口径 |
|---|---|---|---|
| 北极星 | **WAS 周活跃主播有效生成话术条数** | 第 8 周 ≥12,000 | `suggestion_feedback` 中 action=copy/adopt 去重求和 |
| 业务 | 首月注册主播数 | ≥800 | 注册且创建 ≥1 人设 |
| 业务 | 次周留存率 | ≥30% | 注册后 7~13 天内开播 ≥1 场 |
| 体验 | 端到端延迟 P95 | ≤2.5s | 语音结束 → 卡片渲染完成 |
| 合规 | 违规话术漏放率 | ≤0.1% | 人工抽检 1000 条漏放比例 |

> 团长统一口径：延迟按「首字可见 P50 ≤1.2s / P95 ≤1.8s，完整话术 P95 ≤2.5s」验收。

## 二、用户故事（P0）

| 编号 | 故事 | 验收 |
|---|---|---|
| US-01 | 未登录即可进入演示模式看话术卡片 | ≤2 步进入，展示 3 条模拟卡，演示数据不入库 |
| US-02 | 注册并配置人设（性格/风格/类目/禁词） | 表单 4 项，保存后 200ms 内工作台可见 |
| US-03 | 开播后实时收音转写对方语音 | 首字上屏 ≤800ms；断网显示"重连中"，10s 内自动重连 |
| US-04 | 对方说完后看到 3 条可直接照念的候选 | 置信度 >0.8 绿、0.5~0.8 黄、<0.5 灰且默认折叠 |
| US-05 | 一键复制/快捷键切换候选 | 复制 ≤100ms + toast；⌘1/2/3 复制，空格切换 |
| US-06 | 违规表达被拦截并提示 | 红线词 100% 拦截，提供安全替代表述 |
| US-07 | 隐私协议与录音授权 | 首次采集前强制弹窗；未授权前不采集任何音频（抓包验证无上行音频帧） |

## 四、主流程

```
[首页] --点"免费体验"--> [实时辅助页·演示态]
   |
点"开始直播辅助" --> 未登录则 [注册/登录] --> [人设配置]（可套预设模板）
   |
[工作台] --选音源+人设+风格--> [录音授权弹窗]
   |
[实时辅助页]  收音(VAD) -> 流式转写上屏 -> 断句触发生成
                                |
                        合规过滤（命中 -> 重生成 / 标灰警告 / 安全替换）
                                |
                        [话术卡片 ×3] --复制/快捷键--> 主播照念
                                |
                        [👍/👎 打标] --> [金句库] / [沉淀]
                                |
                        [结束直播] --> [战绩复盘]
```

### 异常分支出口

| 异常 | 表现 | 用户出口 |
|---|---|---|
| 录音权限被拒 | 全屏三步图文引导 | 重新授权 / 切"仅文本输入"降级 |
| 无音频输入 | 顶栏变灰"未检测到声音" | 切换音源 / 开降级文本输入 |
| 网络断开 | "连接中断，正在重连…"+ 最近 3 条置灰 | 1/2/4 秒自动重连 3 次 |
| 生成超时 >4s | "正在思考…" + 保留上次成功话术 | ⌘K 手动重生成 |
| 合规命中 | 卡片标红 + 提示气泡 + 安全替代 | 用替代版 / 忽略并记录 |
| 配额用尽 | 弹窗升级 | 升级 / 结束本场（数据仍保存） |

**实时性硬约束**：主话术 ≥32px、行高 1.5、单行 ≤28 字；面板停靠右侧可贴边/透明化，遮挡 ≤25%；所有操作键盘可达；卡片原地替换 + 0.2s 淡入，不做整页跳动（避免主播视线丢失）。

## 六、页面树与数据模型

```
/ 首页 │ /login │ /workspace │ /persona │ /live（核心）│ /live/suggestions
/history │ /golden │ /review │ /pricing │ /settings │ /admin
```

**核心实体**：User（plan、quota_minutes）、Persona（personality、style、category、banned_words[]）、Session（source_type、duration_sec）、Utterance（seq、speaker、is_final、asr_confidence）、Suggestion（content、confidence、latency_ms、risk_level、source、model）、Feedback（action、reason_tag）、GoldenPhrase（tags[]、use_count）。

**埋点**：`signup_success`、`persona_create`、`session_start`、`utterance_final`、`suggestion_shown`、`suggestion_copy`（＝北极星）、`suggestion_feedback`、`risk_blocked`、`golden_add`、`pay_success`。

## 七、内容合规与安全

1. **红线词库 6 类**：广告法极限词、医疗功效、诱导打赏、人身攻击、涉政涉赌、金融承诺，V1.0 内置 ≥2000 词，支持热更新
2. **双层拦截**：生成前注入 System Prompt 禁令（含 5 条绝对禁止项）；生成后红线库检测，命中即标红并提供安全替代；辱骂/涉政等高危直接不出卡并记 `risk_blocked`
3. **诱导打赏专项**：识别"不刷就是不爱我""榜一才有资格"等模式，目标识别率 ≥95%
4. **数据合规**：音频默认不落盘（仅转写文本），可选开启保留 7 天；隐私政策与录音授权为强制前置
5. **免责声明**：卡片底部常驻小字 —— 生成话术仅为建议，合规责任归属主播

## 八、版本路线图

| 版本 | 时间窗 | 范围 | 成功指标 |
|---|---|---|---|
| **V1.0 MVP** | 第 1~6 周 | F-01~F-09（全 P0） | 延迟 P95 ≤2.5s；首月注册 ≥800；采纳率 ≥35% |
| V1.5 | 上线后 2~6 周 | F-10~F-15 | 次周留存 ≥30%；付费转化 ≥5%；金句复用率 ≥20% |
| V2.0 | Q+1 | F-16~F-20 + 移动端只读 H5 | 团队席位 ≥50 家 MCN；API ≥10 万次/月 |

**迭代决策规则**：采纳率 <25% → 优先做预设模板 + 人设引导；次周留存 <20% → 优先沉淀资产；延迟 P95 >3.5s → 暂停新功能，专项做流式与模型降级。
